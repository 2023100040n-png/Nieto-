# Cayao Nieto – Programming Learning Portfolio

A comprehensive web-based portfolio and learning tracker built to document my programming journey, showcase projects, and track skill development.

---

## Project Proposal

### Overview
This project is a **Personal Programming Portfolio & Learning Tracker** — a single-page web application that serves as a central hub for:
- Showcasing projects I have built while learning to program
- Tracking skills and technologies I am learning
- Setting and monitoring learning goals
- Documenting my programming journey with notes and reflections

### Goals
1. **Learn by building** – Apply HTML, CSS, and JavaScript concepts in a real project.
2. **Document progress** – Keep an organized record of completed and in-progress learning milestones.
3. **Share achievements** – Present a clean, professional portfolio to instructors and peers.
4. **Grow continuously** – Use the tracker to identify areas for improvement and set new goals.

### Features
| Feature | Description |
|---|---|
| Hero Section | Introduction with name, tagline, and call-to-action |
| About Me | Brief bio and academic background |
| Skills Tracker | Visual progress bars for each technology |
| Projects Gallery | Cards showcasing completed and in-progress projects |
| Learning Goals | Checklist of current learning objectives |
| Contact | Links to reach me via email or social platforms |

### Technology Stack
| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (Flexbox, Grid, CSS Variables, Animations) |
| Interactivity | Vanilla JavaScript (ES6+) |
| Icons | Unicode symbols / Emoji |
| Hosting | GitHub Pages |

```bash
cd Nieto-

```
